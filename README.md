# ATS Scout

A lightweight Python toolkit for discovering, collecting, and monitoring job postings directly from applicant tracking systems (ATS).

## Overview

ATS Scout provides a unified interface for retrieving job postings from multiple ATS platforms. Designed for use with AI agents, automation workflows, and command-line tools.

### Supported Platforms

- Greenhouse
- Lever
- Ashby

## Planned Features

- Unified API for retrieving and normalizing job postings
- Job filtering by title, location, salary, and employment type
- Company discovery and ATS identification
- Job tracking, deduplication, and change detection
- CLI for searching and retrieving jobs
- MCP server integration for AI agents

## Tech Stack

- **Language:** Python
- **HTTP Client:** HTTPX
- **Data Models:** Pydantic
- **CLI:** Typer
- **Storage:** SQLite
- **Agent Integration:** Model Context Protocol (MCP)
